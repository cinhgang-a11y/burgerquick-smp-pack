# Opening the BurgerQuick models in Blockbench

These are written by `generate.py` (run it again after any change to regenerate them).

## Opening one
1. Blockbench → **File → Import → Import Java Block/Item Model**, pick a `.json` here.
2. The texture will show as missing: in the **Textures** panel hit **+**, pick the matching `.png`
   (`tyrant.png` for the dragon parts, `worldbreaker_3d.png` / `earthquake_mace_3d.png` for the hammers).

## Which file
- `tyrant_whole.json` — the entire dragon assembled the way the plugin poses it. Best for judging
  proportions. **Don't edit this one**; it is generated from the parts.
- `tyrant_body/head/wing_l/wing_r/tail.json` — the five parts the plugin animates separately.
  Edit these.
- `worldbreaker_3d.json`, `earthquake_mace_3d.json` — the war hammers.

## Rules the plugin depends on
- Every part rotates around the model centre **(8, 8, 8)** — that point is its hinge (neck joint,
  wing shoulder, tail base). Keep the part positioned around it or the animation will swing wrong.
- The dragon faces **north (-Z)**. Forward is -Z, the head is at -Z, the tail at +Z.
- Element coordinates must stay within **-16..32**, or the client rejects the whole model silently.
- The left wing is generated by mirroring the right one, so only edit `tyrant_wing_r`.

## Sending changes back
Save your edited part (Blockbench: **File → Export → Java Block/Item Model**) anywhere and tell
Claude the path. It reads the JSON and folds the shape back into `boss_model.py` /
`mace_model.py`, which stay the source of truth. Screenshots work too if you just want to point at
what looks wrong.
