# BurgerQuick SMP Resource Pack

Custom textures for the 41 custom items on BurgerQuick SMP (Minecraft 26.2).

- **Download:** [BurgerQuick-Textures.zip](BurgerQuick-Textures.zip)
- Put it in `.minecraft/resourcepacks` and enable it in Options → Resource Packs.
  (The server also offers it automatically when you join.)

Everything is in the `burgerquick` namespace, so no vanilla item is changed.

`generate.py` draws every texture and rebuilds the pack: `python generate.py`
